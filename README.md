# FlareX

## Satellite-Based Thermal Anomaly Intelligence System

### Overview
FlareX is an AI/ML and geospatial intelligence project designed to analyse satellite-based thermal anomaly observations, identify unusual patterns, and assess potential geographical risk.

### Objectives
- Collect satellite thermal anomaly data.
- Perform data cleaning and preprocessing.
- Analyse spatial and temporal patterns.
- Develop machine learning-based anomaly detection models.
- Incorporate geographical context.
- Visualise findings through an interactive dashboard.

### Initial Data Source
NASA FIRMS – VIIRS (JPSS-2)

### Technology Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- GeoPandas
- PyTorch (planned)
